# Credits

`skill-authoring` draws on three MIT-licensed skills:

- **Matt Pocock's `writing-for-agents`**, https://github.com/mattpocock/skills/tree/main/skills/productivity/writing-for-agents (commit `49dd158d`): `references/wording.md` summarises it, and the description rules follow its context pointers.
- **GitLab's `authoring-skills`**, https://gitlab.com/gitlab-org/ai/skills/-/tree/main/skills/authoring-skills (commit `c12add8c`): the description as trigger, the body shapes, and the trigger, cold-read and real-task checks.
- **pstack's `unslop`** by Lauren Tan, https://github.com/cursor/plugins/tree/main/pstack/skills/unslop (commit `d4575673`): the punctuation rules in the unslop check.

The scope, plan, name, body parts, project file and install rules are new.
